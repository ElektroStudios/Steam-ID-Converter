## 👋 Introduction

**Steam ID Converter** is a Windows desktop application that allows you to convert between SteamID32 and SteamID64 identifiers.

> [!NOTE]
> This tool supports only the account number portion of a Steam ID. It does not identify the Steam ID type or its universe (domain).

More info about the Steam ID structure is available at [SteamID wiki](https://developer.valvesoftware.com/wiki/SteamID).

## 💡 Motivation

Manually converting Steam IDs between 32-bit and 64-bit formats is a tedious bottleneck when dealing with game configuration files and account-specific user data. Many game configuration layouts, text-based parameters, and specialized initialization files—such as `codex.ini`, `steam_api.ini`, `steam_emu.ini`, or `tenoke.ini`—require accurate account identifiers in either specific bit lengths, decimal values, or hexadecimal notation to function properly.

Instead of wasting time performing manual mathematical calculations or depending on third-party web-based converters, this tool offers a local, offline environment to automatically detect, process, and execute the required identifier conversion on the spot.

##### ⚡ The Real Question
###### How many different Steam ID formats do you have to guess and test before a game configuration file or a foreign save game finally stops rejecting your account identifier?.

## 📋 Features

 - Automatically detects the format of the input Steam ID and performs the appropriate conversion.
 - Can convert a SteamID32 to SteamID64.
 - Can convert a SteamID64 to SteamID32.
 - Supports both decimal and hexadecimal Steam ID representations.

## 🤖 Use cases

Obtaining a SteamID32 or SteamID64 in the correct format can be useful in several scenarios.

For example, it allows you to adapt save files created by another user (a different Steam ID than yours) so they can be used under your own account. It can also be helpful when editing configuration files or tools that require a valid Steam account identifier in the correct format, like configuration files ommonly associated with pirated video game cracks, such as `codex.ini`, `CPY.ini`, `ds.ini`, `REVOLT.ini`, `steam_api.ini`, `steam_emu.ini`, `tenoke.ini` and others, which expects to specify an SteamID32 or SteamID64 in the appropriate format.
